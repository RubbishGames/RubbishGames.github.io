# Generation & Star Sign Finder  

## Overview  
This is a simple web-based tool that allows users to determine their generational category and zodiac sign based on their date of birth. The tool provides instant results using JavaScript and a clean, responsive design.  

## Features  
- Determine your generation based on your birth year.  
- Identify your zodiac sign based on your birth date.  
- Simple, user-friendly interface with a dark theme.  
- Instant results with a single button click.  

## Technologies Used  
- **HTML**: Structure of the page.  
- **CSS**: Styling and layout.  
- **JavaScript**: Logic for calculating generation and zodiac sign.  

## How to Use  
1. Open ain your web browser and go to "https://rubbishgames.github.io/ ".  
2. Enter your date of birth in the input field.  
3. Click the **Find** button.  
4. The tool will display your generation and zodiac sign.  

## Compatibility  
- Works on modern web browsers (Chrome, Firefox, Edge, Safari).  
- Fully responsive and mobile-friendly.
